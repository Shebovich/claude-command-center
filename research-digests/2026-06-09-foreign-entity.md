# Юрлицо за рубежом для белоруса под Stripe/Paddle (приём международных платежей)

**Дата:** 2026-06-09
**Под кого:** Pavel, ИП-предприниматель из Минска (РБ). Цель — продавать цифровые продукты/SaaS глобально. Из РБ Stripe/Paddle/Lemon Squeezy/Wise закрыты по санкциям. Бюджет ограничен, соло.

---

## TL;DR (если читать одну строку)

**Делай US LLC (Wyoming или Delaware) через Stripe Atlas или дешёвый регистратор → Stripe включается сразу, банк Mercury, вывод через Payoneer на небелорусскую карту/крипту.** Это единственный из рассмотренных вариантов, где Stripe и Paddle реально работают «из коробки». Все локальные альтернативы (Казахстан / Грузия / Армения) Stripe НЕ дают — там максимум Payoneer, а это уже не «нормальная платёжка для SaaS».

---

## Критичный факт №1: как именно санкции бьют по Stripe

Stripe блокирует по **местоположению аккаунта/бизнеса**, а не по гражданству бенефициара напрямую:
- «Stripe currently does not support users **located in** Russia, Ukraine and Belarus.» — то есть нельзя открыть Stripe на компанию/человека *в* РБ.
- OFAC «50% rule»: автоматически заблокирован только тот, кто на **50%+ принадлежит лицам из санкционного SDN-списка**. Обычный белорус, не в списке SDN, владеющий US LLC — НЕ заблокирован автоматически.
- НО: при KYC белорусский паспорт бенефициара = повышенный риск, могут запросить доп. документы, дольше верификация, иногда отказ. Это «решаемо, но надо быть готовым».

**Вывод:** US LLC, где Pavel — единственный владелец с белорусским паспортом, Stripe в принципе допускает. Контролируемый риск — KYC на этапе верификации, не запрет по гражданству.

## Критичный факт №2: локальные юрисдикции Stripe НЕ открывают

- **Казахстан** — Stripe официально страну НЕ поддерживает для открытия мерчант-аккаунта (поддержка только сбора VAT для удалённых digital-продавцов). Подключить Stripe «на ТОО» напрямую = либо невозможно, либо высокий риск отказа/блокировки (СНГ = high-risk).
- **Грузия** — Stripe нет. На грузинское ИП/ООО Stripe не открывается.
- **Армения** — Stripe нет вообще. Работает только Payoneer (и тот ограниченно), Wise/PayPal-приём — нет.

То есть «открою фирму в КЗ/ГЕ/АМ и подключу Stripe» — миф. В этих странах решают задачу **инвойсинга через Payoneer**, а не приёма карточных платежей за SaaS.

## Сравнение вариантов (реальные цифры, 2026)

### 1. США — LLC через Stripe Atlas (или дешевле напрямую)

| | |
|---|---|
| Открытие | Atlas: **$500** (LLC/C-Corp, EIN, registered agent на год, шаблоны, заявка на Mercury). Альтернативы (doola/Firstbase/Bizee) — от ~$0–300 + госпошлина штата. |
| Годовая | Wyoming: registered agent ~$100–200/год + annual report ~$60. Delaware: franchise tax **$300/год** + agent $100–200. **Form 5472** (обязателен для foreign-owned single-member LLC) — обычно через CPA **$300–800/год** (Atlas НЕ включает!). Итого реально **$700–2500/год** с бухгалтером. |
| Удалённо из Минска | **Да**, полностью. Личного визита не нужно. |
| Stripe/Paddle | **Да, открывает сразу.** Atlas интегрирован со Stripe. Paddle/Lemon Squeezy на US LLC тоже работают. |
| Банк | Mercury (Atlas подаёт заявку), но в 2025–2026 Mercury ужесточил KYC для нерезидентов — дольше ревью, доп. документы, бывают отказы новым компаниям без выручки. Запасные: Wise Business (для US LLC доступен), Payoneer, Relay, Brex. |
| Налоги | Foreign-owned single-member LLC без US-присутствия и US-source income обычно **federal income tax = 0**, но **обязательны** ежегодные Form 5472 + pro-forma 1120 (штраф за непод. 5472 — **$25 000**). Это бумажная, а не денежная нагрузка. |
| Вывод в РБ | Stripe payout → Mercury/Payoneer → крипта или карта небелорусского банка. Payoneer бизнес-счёт для US LLC доступен; вывод напрямую на банк РБ Payoneer режет (санкц. банки), поэтому через карту неподсанкц. банка / крипту. |
| Сроки | Регистрация 1–7 дней, EIN 1–4 недели (для иностранца без SSN дольше), Stripe — сразу после Atlas. |
| Риски | KYC по белорусскому паспорту (Stripe/Mercury могут тормознуть/отказать), обязательная отчётность 5472 (дорого пропустить), нужен CPA. |

### 2. Казахстан — ТОО (+ Astana Hub / AIFC)

| | |
|---|---|
| Открытие | ТОО нерезидент открыть может; **ИП — только с ВНЖ**. AIFC: регистрация от **$300**, госпошлина **$500**, продление **$1000–2000/год**. Astana Hub: сопровождение от ~500 тыс. тенге (~$1000), рассмотрение 30–45 раб. дней. |
| Удалённо | ТОО — да, но **ИИН (ИИН-номер) с 24.02.2024 нужно получать ЛИЧНО в ЦОН в Казахстане** — удалённо по доверенности/через посольство больше нельзя. Т.е. без поездки в КЗ полноценно не закрыть. |
| Stripe/Paddle | **НЕТ.** Stripe Казахстан не поддерживает. Максимум — local-эквайринг и Payoneer. |
| Налоги | AIFC/Astana Hub — льготы (освобождение от КПН/НДС для квалиф. IT до 2066 г.), вне льгот — стандартный КПН 20% / упрощёнка. |

|---|---|

| Итог | Дёшево и 1% налог — отлично для **фриланс-инвойсинга через Payoneer/Wise**, но **Stripe не открывает** + новое разрешение на работу с 03.2026. |

### 4. Армения — ИП (IT 1%)

| | |
|---|---|
| Открытие | Удалённо по нотар. доверенности через местного представителя. Гербовый сбор 5000 драм/мес (~$12,5). |
| Stripe/Paddle | **НЕТ.** Stripe в Армении нет. Wise/PayPal-приём нет. **Только Payoneer** (есть положительный опыт приёма, в т.ч. на корпоративный Payoneer). |
| Налоги | IT/оборот до ~120 млн драм (~$300k) — **1% с оборота**. |
| Вывод в РБ | Армянский банк (нерезидентам открывают, но смотрят на прозрачность бизнеса) или Payoneer. Армения не санкционна, переводы в РБ живые. |
| Итог | Самый дешёвый «налогово», но **Stripe нет** — это путь Payoneer-инвойсинга, не SaaS-эквайринга. |

### 5. Кратко — ОАЭ и Эстония

- **ОАЭ (Free Zone):** Stripe UAE поддерживает, но открытие дорогое (free-zone лицензия ~$3000–6000+/год, нужен резидент-визовый процесс, часто визит). Для соло с ограниченным бюджетом — избыточно дорого. Не рекомендую на старте.
- **Эстония e-Residency:** **для белорусов фактически закрыта.** Первичные заявки граждан РБ по умолчанию НЕ рассматриваются (исключение — если 3+ года прожил в ЕЭЗ/UK/Швейцарии). Плюс Wise режет карты гражданам РБ без резиденции в ЕЭЗ. **Не вариант.**

## РЕКОМЕНДАЦИЯ

**№1 — США LLC (Wyoming или Delaware) под Stripe.** Единственный реально работающий способ получить Stripe/Paddle для продажи SaaS глобально. Локальные юрисдикции (КЗ/ГЕ/АМ) Stripe не дают — там потолок Payoneer, что для карточного приёма за подписки не годится.

**Когда выбрать НЕ США:** если Pavel готов отказаться от Stripe и жить на Payoneer-инвойсинге (B2B-выставление счетов, не self-serve карты) — тогда **Грузия ИП 1%** самый дешёвый (но учесть разрешение на работу с 03.2026), либо **Армения ИП 1%**. Для SaaS с самостоятельной оплатой картой это не замена Stripe.

### Честные подводные камни США-варианта
1. **KYC по белорусскому паспорту** — Stripe и особенно Mercury могут затянуть/отказать. План Б по банку обязателен (Wise Business / Payoneer / Relay).
2. **Form 5472** — обязателен ежегодно, штраф $25k за пропуск. Нужен CPA (~$300–800/год). Это главная скрытая стоимость.
3. **Вывод в РБ напрямую не идёт** — Payoneer/банки режут санкционные банки РБ. Работает через крипту или карту неподсанкционного банка (напр. через third-country). Это серая зона по комплаенсу — держать в уме.
4. Atlas-цена $500 — только регистрация; реальная годовая нагрузка $700–2500.

### Пошаговый старт (топ-вариант, US LLC)
1. Выбрать штат: **Wyoming** (дешевле: нет franchise tax, agent ~$100–200) или Delaware (престижнее, но +$300/год). Для соло-SaaS — Wyoming.
2. Зарегистрировать LLC: **Stripe Atlas $500** (всё в одном + сразу Stripe + заявка Mercury) ИЛИ дешевле через doola/Firstbase, но тогда Stripe/банк подключать руками.
3. Получить **EIN** (Atlas делает; для иностранца без SSN — через SS-4, 1–4 нед).
4. Открыть банк: **Mercury** (или Wise Business / Payoneer как запасной). Заложить риск KYC по паспорту.
5. Подключить **Stripe** (через Atlas — автоматом) + при желании Paddle/Lemon Squeezy как Merchant of Record (берут на себя налоги/VAT — удобно соло).
6. Нанять **CPA** под Form 5472 + pro-forma 1120 (раз в год). НЕ пропускать.
7. Настроить вывод: Stripe → Mercury → Payoneer → крипта/карта неподсанкц. банка → в РБ. Протестировать на малой сумме.
8. Бюджет на старте: **~$500–700 открытие + ~$700–1500/год** (agent + report + CPA/5472).

> Подсказка по упрощению налогов/VAT: рассмотреть **Paddle или Lemon Squeezy как Merchant of Record** поверх US LLC — они сами считают и платят VAT/sales tax с твоих клиентов по миру, что сильно снимает головную боль соло-фаундеру (минус — их комиссия выше Stripe).
