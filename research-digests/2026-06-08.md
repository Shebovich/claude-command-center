## ТРЕК 1 — ИНЖЕНЕР (рост как разработчик)

**1. Dynamic Workflows в Claude Code (research preview, май 2026).**
Одна сессия оркестрирует десятки–сотни субагентов в фоне через `/workflows`. Claude сам пишет JS-скрипт оркестрации, runtime крутит до 16 параллельно, кап 1000 агентов на запуск.
Источник: https://www.marktechpost.com/2026/05/28/anthropic-ships-claude-opus-4-8-alongside-dynamic-workflows-and-cheaper-fast-mode-with-workflows-capped-at-1000-subagents/
→ **Что делать:** для массовых задач (сгенерить 30 лендингов под SaaS-конвейер, прогнать рефакторинг по репам) пробовать `/workflows` вместо ручного фан-аута. Идеально ложится на «много SaaS» из SAAS-PLAYBOOK.

**2. Reusable субагенты как YAML-конфиги в `.claude/agents/`.**
Кастомный system prompt + выбор модели + права на инструменты, вызов по имени. У Pavel уже лежат `content-critic.md`, `scriptwriter.md`, `lab-analyzer.md`, `hook-doctor.md` — это ровно тот паттерн.
Источник: https://www.cloudzero.com/blog/claude-code-agents/
→ **Что делать:** закрепить как стандарт — под каждый повторяемый процесс (review, scriptwriting под reels, expense-парсинг) отдельный субагент с дешёвой моделью (Sonnet/Haiku) где не нужен Opus. Экономия токенов.

**3. Hooks стали мощнее: `Stop`/`SubagentStop` возвращают `additionalContext`, новый `MessageDisplay` hook.**
Хуки теперь могут подмешивать контекст обратно агенту и трансформировать сообщения при выводе. Плюс `disallowed-tools` во frontmatter скилла и `/reload-skills` без рестарта.
Источник: https://releasebot.io/updates/anthropic/claude-code
→ **Что делать:** в personal-assistant контур — хук на `Stop` для авто-проверки «ответ в чат-стиле, без markdown» (есть feedback_reply_formatting). `/reload-skills` ускорит итерацию по скиллам.

**4. Fallback-модели (до 3 по очереди) при перегрузе primary.**
Настройка пробует резервные модели, когда основная overloaded/недоступна.
Источник: https://releasebot.io/updates/anthropic/claude-code
→ **Что делать:** прописать fallback Opus→Sonnet→Haiku, чтобы poller personal-assistant не падал в часы перегруза API.

**5. Консенсус по workflow-дисциплине 2026: plan → small diffs → tests → PR gate.**
Рабочий дефолт — планировать локально, агент исполняет в песочнице, обязательны CI + PR review до merge; человеческий аппрув на auth/payment/deps/config-изменения.
Источник: https://kilo.ai/articles/beyond-autocomplete · https://addyosmani.com/blog/ai-coding-workflow/
→ **Что делать:** для SaaS-конвейера завести шаблон: тесты до автономного агента, мелкие диффы, stop-rules. Особенно жёстко — на платёжной логике (MoR-интеграции).

## ТРЕК 2 — БИЗНЕСМЕН (рост как предприниматель)

**1. Кейс Kleo — $62K MRR за ~6 мес, чистая дистрибуция через аудиторию.**
LinkedIn-контент-тул; рост на 480K+ совокупной аудитории фаундеров + пред-лонч вебинары (по $5K+ каждый) + виральные посты. Деньги сделала дистрибуция, не продукт.
Источник: https://tamimbuilds.medium.com/8-solo-founders-who-quietly-hit-20k-62k-mrr-in-the-last-6-months-5032e610badc
→ **Что делать:** vibecode.by reels — это и есть твоя дистрибуция. Каждый новый SaaS лончить НА аудиторию бренда, а не «в пустоту на Product Hunt». Прогревать пред-лонч контентом.

**2. Founder-led маркетинг бьёт корпоративный 10:1 и стоит $0.**
В 2026 решает «показываться лицом» (даже faceless — личный голос/история), а не бюджет. Photo AI ($132K MRR) и Chatbase ($50K MRR через TikTok) — оба на личном бренде фаундера.
Источник: https://marketingcrafted.com/playbooks/saas-marketing-strategy · https://crazyburst.com/ai-saas-solo-founder-success-stories-2026/
→ **Что делать:** держать ритм публикаций как первый канал привлечения. Публичный build-in-public (revenue, процесс) усиливает faceless-бренд.

**3. Pricing сместился на usage/credit/hybrid — flat per-seat умирает для AI.**
74% вендоров уже на usage-based; 43% на hybrid (база + переменная часть), к концу 2026 прогноз 61%. Cursor, Perplexity, Claude — все на кредитах. Flat-тариф не покрывает токен-косты AI-продукта.
Источник: https://www.getmonetizely.com/blogs/the-2026-guide-to-saas-ai-and-agentic-pricing-models · https://www.pymnts.com/news/artificial-intelligence/2026/ai-moves-saas-subscriptions-consumption/
→ **Что делать:** дефолт pricing для новых SaaS — hybrid: дешёвая база (под MoR-чек) + кредиты на AI-операции. Это защищает маржу от token-burn. Осторожно с щедрыми триал-кредитами (шок на инвойсе ×5–10).

**4. Валидация платящим, не лайком: 20+ email до кода, $1 платёж = ×10 к free-сигапу.**
Медиана до $10K MRR у bootstrapped micro-SaaS — 12–18 мес; 70% micro-SaaS делают <$1K/мес. Лендинг → 20+ подписок → бета за деньги, иначе менять позиционирование.
Источник: https://superframeworks.com/articles/best-micro-saas-ideas-solopreneurs
→ **Что делать:** в SAAS-PLAYBOOK воткнуть гейт: не пишем код, пока нет 20 email / 1 предоплаты. Лендинг можно собрать тем же CC за час.

**5. Предупреждение: 90% «AI-wrapper» стартапов умрут к концу 2026, маржа 25–35% vs 70–85% у нормального SaaS.**
Голый враппер вокруг API без своей дистрибуции/данных/вертикали не выживает.
Источник: https://www.nxcode.io/resources/news/micro-saas-ideas-2026
→ **Что делать:** каждый твой SaaS должен иметь несводимый к API моат — либо вертикальная глубина, либо твоя аудитория как дистрибуция, либо проприетарный workflow/данные.

## ТРЕК 3 — РАЗВЕДКА НИШ (где деньги, под профиль Pavel)

→ **Почему Pavel:** твоя зона экспертизы (CC, субагенты, hooks). Продаёшь dev-аудитории = пересекается с аудиторией vibecode.by. Контент и продукт кормят друг друга.

**3. Telegram group-management SaaS (антиспам, бан-ботов, welcome-флоу, правила).**
Продаёшь комьюнити-менеджерам и владельцам крупных TG-групп как сервис.

**4. YC RFS Spring 2026: «Company Brain» + «AI-native service company».**
YC явно хочет (а) систему, что вытаскивает знания из Slack/Notion/GitHub/тикетов в исполняемый skills-файл для агентов; (б) «продавать готовую работу, а не софт». Соло-операторы AI-агентств: $10–30K/мес на 20+ клиентах при ~80% автоматизации.
Источник: https://www.ycombinator.com/rfs · https://superframeworks.com/articles/yc-rfs-startup-ideas-indie-hackers-2026
→ **Почему Pavel:** микро-версия Company Brain под одну вертикаль (напр. «мозг для TG-комьюнити» или для агентства) — посильна соло на CC. Модель «продаём результат» = твой existing personal-assistant контур, упакованный для клиента.

**5. Productized AI-automation для underserved «синих воротничков» (trades/field techs).**
Трейд-воркеры и полевые техники недообслужены, готовы платить за экономию времени, конкуренция почти нулевая (vs очередной project-mgmt тул).
Источник: https://monolit.sh/blog/why-indie-hackers-are-winning-against-funded-startups-2026
→ **Почему Pavel:** не AI-враппер (есть моат — вертикаль + workflow), не consumer-гонка. TG-бот как интерфейс для не-технической аудитории = твой конёк. Можно стартовать на белорусском/русскоязычном рынке.
